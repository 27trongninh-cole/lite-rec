# Lite Rec

Bong bóng nổi quay màn hình + âm thanh hệ thống, lưu vào `Movies/`. Không Gradle, không thư viện ngoài (APK vài chục KB).

- Video: H.264 High, cạnh dài 2160, 16 Mbps VBR, 30 fps, encoder phần cứng nhận thẳng Surface.
- Âm thanh: AudioPlaybackCapture -> AAC 128 kbps stereo 48 kHz.
- Chỉnh chất lượng ở các hằng số đầu `Recorder.java`.

Tải APK: `https://github.com/<user>/<repo>/releases/latest/download/app.apk`
